## 1. 自己紹介・きっかけ

> 「」

**話すポイント：** 「心配だから」「でもすぐには行けないから」の2つを、
表情や声のトーンで伝える。ここが共感を生む一番大事なところ。

## 2. 困っていること

- 地震が多くて心配。でも遠くてすぐ助けに行けない
- おじいちゃんおばあちゃんは、スマホの操作が難しい
- 一人だけで防災対策をするのは、大変だし、続かない

## 3. 考えたアイデア

> 「一人でがんばるのではなく、**孫とおじいちゃんおばあちゃんが
> 一緒に**防災対策を進められたらいいなと思いました。」

- 離れていても、スマホ越しに「一緒に」やる
- 難しいことは孫がサポートする
- おじいちゃんおばあちゃんは、簡単な操作だけでOK

## 4. アプリの紹介

作った「ぼうさいアプリ」には、こんな機能があります。

| 機能 | 内容 |
|---|---|
| 安否確認 | ワンタップで「無事です」を家族に伝える |
| 防災チェックリスト | 非常持ち出し袋などを、孫と確認しながら進める |
| **お部屋防災診断（AI）** | お部屋の写真をAI（Gemini）が見て、危ないところを教えてくれる。祖父母・孫が両方チェックすると「できた！」になる |
| 毎日の体調共有 | 「元気」「普通」「元気がない」の3段階で、毎日の体調を孫に伝える |
| 曜日ごとのボイス | 孫が録音した声のメッセージを、祖父母が「無事です」を押すと自動で再生 |
| 育成ゲーム要素・ミニゲーム | みんなで防災に取り組むと、家族みんなの「ぼうさいキャラクター」が一緒に育つ |

**話すポイント：** 全部を細かく説明しなくてOK。
「一番自信のある機能（お部屋防災診断のAI診断）」に時間をかける。

## 5. 実際の使い方（デモ）— AIお部屋防災診断を中心に

1. おじいちゃんが、自分の部屋の写真を撮ってアプリに送る
2. AI（Gemini）が写真を見て、数秒で危ないところにマークをつける
3. マークをタップすると「ここが危ない」「対策のポイント」が出てくる
4. おじいちゃんと孫が、それぞれ自分のスマホで「できた！」を押す
5. **二人ともチェックした瞬間に、自動で「🎉 二人で対策できました！」**になる（片方だけでは完了しない）

**話すポイント：** ここは実演（デモ）や写真つきスライドで見せると
一番伝わる。「会話しているみたい」に発表するとよい。片方だけでは完了しない
ところを見せると、「一人じゃなく二人でやる」ことが一目で伝わる。

## 6. 工夫したところ

- **孫モードとおじいちゃん・おばあちゃんモードで、画面の見た目そのものを変えた**
  （孫＝青系・ふつうの文字サイズ・やさしい表記、祖父母＝オレンジ系・文字1.25倍・ふつうの漢字）。
  タブを切り替えた瞬間に見た目が変わるので、「どちらのモードか」が一目でわかる
- AIの診断結果は「絶対にこう」と決めつけず、「AIの見立てなので、ちがうときもあります」と
  必ず添えるようにした。もし違うと感じたら、その場でマークを消せるようにもした
- 「診断してあげる」ではなく「一緒に見る」形にして、
  おじいちゃんおばあちゃんが自分から取り組みたくなるようにした
- 対策の完了は、**祖父母と孫が別々に「できた！」を押して、両方そろって初めて完了**にした。
  片方の代理では完了しないので、本当に二人でやったことになる
- 毎日の体調は、文章を打たなくても3段階のボタンを押すだけで伝えられるようにした
- 育成ゲーム要素を入れて、防災対策や体調共有を「楽しく続けられる」ようにした
- 安否確認の「無事です」を押すと、孫が録音した声が流れるようにして、
  ボタン一つの操作でも気持ちが伝わるようにした

## 7. おじいちゃん・おばあちゃんへの思い

> 「離れていても、私はいつもおじいちゃんおばあちゃんのことを
> 考えています。このアプリで、もしものときも、普段のときも、
> ずっとつながっていたいです。」

## 8. これからやってみたいこと

- 地震情報と連携して、自動で安否確認が届くようにしたい
- 祖父母・孫がそれぞれ別のスマホからでも使えるように、サーバーでデータをつなげたい
- もっとたくさんの家族に使ってもらいたい
